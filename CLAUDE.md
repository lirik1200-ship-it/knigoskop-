# Книгоскопъ

Браузерная игра по русской литературе для школьников 8–11 классов: ученик смотрит панорамную сцену и определяет литературное направление, место действия, автора (по портрету) и название произведения.

## Устройство
- `index.html` — вся игра одним файлом: разметка, стили (`<style>` в начале), логика и данные (`<script>` в конце). Сборки нет, открывается двойным щелчком.
- `img/` — `l_*.webp` кольцевые панорамы, `s_*.webp` превью, `t_*.webp` миниатюры, `p_*.webp` портреты, `emblem.png` эмблема.
- Данные в скрипте: `ROUNDS` (сцены), `AUTHORS`, `SPOTS` (скрытые детали), `EGE` (вопросы), `MAP` (карта).

## Нельзя менять
- Логику игры, подсчёт очков, id элементов и классы, на которые ссылается скрипт.
- Тексты сцен, загадок, вопросов и ответов.
- Скрытые детали (`.spot`) должны оставаться невидимыми, без подсветки.
- Код с `claude.use(...)` (кабинет учителя, уроки) — он работает только внутри Claude, вне Claude тихо отключается.

## Проверка
Открыть `index.html` в браузере и пройти одну сцену целиком: осмотр, шкала направлений, карта, выбор автора, название, экран результата, вопрос ЕГЭ, итоги. Проверить ширину телефона (390 px) и компьютера.
