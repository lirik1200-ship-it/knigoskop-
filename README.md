# Книгоскопъ

Игра по русской литературе. Ученик оказывается внутри сцены из произведения, осматривается и определяет:
литературное направление, место действия, автора (по портрету) и название.

В игре 37 сцен из программы 8–11 классов, скрытые детали-загадки, вопрос в духе ЕГЭ после каждой сцены,
командный режим для проектора и личная «библиотека» угаданных произведений.

## Как запустить

- **На компьютере:** распакуйте архив и откройте `index.html` в браузере (Chrome, Edge, Safari, Firefox).
  Для красивых шрифтов нужен интернет; без него игра работает со стандартными шрифтами.
- **На сайте (GitHub Pages):** загрузите содержимое папки в репозиторий, затем
  Settings → Pages → Source: ветка `main`, папка `/ (root)`. Игра откроется по адресу
  `https://<ваш-логин>.github.io/<репозиторий>/`.

## Что работает только в Claude

«Кабинет учителя» и «Урок по коду» (сбор результатов класса) используют хранилище Claude
и работают только в версии игры, открытой в Claude. В скачанной версии эти кнопки
не собирают результаты — всё остальное работает полностью.

## Состав

- `index.html` — вся игра (код, стили, карта, тексты).
- `img/` — сцены (`l_` панорамы, `s_` превью, `t_` миниатюры), портреты `p_`, эмблема.

Портреты писателей — из Викисклада (общественное достояние). Сцены сгенерированы нейросетью.
